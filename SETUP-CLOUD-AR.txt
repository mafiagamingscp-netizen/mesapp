تشغيل الواتساب التلقائي 24 ساعة من الموبايل فقط (من غير كمبيوتر)

فكرة التشغيل: التطبيق بيجدول الرسائل في Firebase، وسيرفر مجاني على الإنترنت بيبعتها لوحده. جلسة واتساب محفوظة في Firebase فمش بتحتاج تربط تاني لو السيرفر اتعاد تشغيله.

1) GitHub (github.com من متصفح الموبايل): اعمل حساب ← New repository (اسمه lastvix-wa، Private) ← Add file ← Upload files ← ارفع: server.js و package.json و render.yaml ← Commit.
2) Render (render.com): سجّل بحساب GitHub ← New ← Web Service ← اختار الريبو ← Instance Type: Free ← ضيف Environment Variables:
   ADMIN_EMAIL = ad123@lastvix.app
   ADMIN_PASS  = باسورد حساب الأدمن في Firebase
   PAIR_PHONE  = رقم واتساب اللي هيبعت بكود الدولة مثل 201012345678
   PAGE_TOKEN  = أي كلمة سرية طويلة تختارها
   ثم Create Web Service وانتظر لحد ما يبقى Live.
3) افتح  https://اسم-الخدمة.onrender.com/code?t=PAGE_TOKEN  هيظهر كود من 8 حروف.
   في واتساب (نفس الموبايل): الأجهزة المرتبطة ← ربط جهاز ← "الربط برقم الهاتف بدلًا من ذلك" ← اكتب الكود. (مرة واحدة)
4) عشان السيرفر ما ينامش (Render المجاني بينام بعد 15 دقيقة): سجّل في uptimerobot.com (مجاني) ← Add New Monitor ← HTTP(s) ← الرابط https://اسم-الخدمة.onrender.com/health ← كل 5 دقايق.
5) Firebase: Authentication ← Users ← حساب ad123@lastvix.app موجود وUID بتاعه في admins، وانشر القواعد الجديدة (rules-additions.json).
6) في التطبيق: الإعدادات ← 💬 رسائل واتساب ← ☁️ الإرسال التلقائي السحابي ← مفعّل ← جدولة الآن. ← عرض الحالة بيوريك اللي اتبعت.

ملاحظات صريحة:
- الإرسال بيتم بين 8 صباحًا و10 مساءً بتوقيت القاهرة، بفاصل عشوائي بين الرسائل، وحد 120 رسالة يوميًا لكل جيم و300 إجمالي. غير رسمي: الرقم ممكن يتحظر.
- الجدولة السحابية شغالة للجيمات اللي ترخيصها مفعّل من لوحة الأدمن (عشان محدش يستخدم رقمك للسبام).
- التطبيق لازم يتفتح مرة كل فترة عشان يجدول رسائل الأيام الجاية (بيجدول تنبيهات لحد 40 يوم قدام لكل مشترك مرة واحدة، والسيرفر يبعتها في ميعادها حتى لو التطبيق مقفول).
- الاستضافة المجانية ممكن تتغير شروطها. لو اتحدد أو وقف، ابعتلي وأنقلها لمكان تاني.
