أسهل طريقة (ويندوز): ثبّت Node.js من nodejs.org، ثم دوس مرتين على START-WINDOWS.bat. هتفتح صفحة فيها QR امسحه من واتساب (مرة واحدة)، وانسخ التوكن من الشاشة السوداء وحطه في التطبيق.
لازم الجهاز يفضل شغال عشان الرسائل تتبعت تلقائيًا.

1) ثبّت Node.js 18+ على جهازك.   2) داخل المجلد: npm install   3) npm start
4) امسح كود QR بواتساب (الأجهزة المرتبطة). 5) انسخ التوكن اللي بيظهر، وحطه في التطبيق مع عنوان الجهاز مثل http://192.168.1.5:3000
- الرسائل بتتبعت بفاصل عشوائي 8-20 ثانية وبحد 150 يوميًا (عدّلهم في config.json) لتقليل الحظر.
- غير رسمي: الرقم ممكن يتحظر. لا تفتح البورت للإنترنت. التوكن سري.
- مجلد auth فيه جلسة واتساب: لا تشاركه.
